# ZABOR

Приложение для общения

##  Основные особенности
- **Голосовые каналы:** Высококачественный звук с использованием P2P Mesh WebRTC (трафик между пользователями)
- **Социальные функции:** Система друзей, статусы в реальном времени и управление профилем
- **Геймификация:** Скрытые достижения и система ачивок

##  Технологический стек
- **Frontend:** React 18, TypeScript, Tailwind CSS
- **Backend:** C# / .NET 10.0, SignalR
- **Media:** WebRTC

##  Разработка

### Предварительные условия
[Node.js](https://nodejs.org/) и [npm](https://www.npmjs.com/).

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Сборка приложения
```bash
# Создание NSIS-инсталлятора
npm run dist:win
```

##  Установка для пользователей
Просто качайте из релизов да и все тут

> [!NOTE]
> При установке Windows SmartScreen может выдать предупреждение. Нажмите «Подробнее» -> «Выполнить в любом случае»
